# JOD GET

JOD GET is a full-stack job search helper concept. The app is designed to help people find jobs, save opportunities, track applications, and organize the steps needed to get hired.

## Current project stage

This repository currently contains the first product design artifact: a Figma-ready UI model and wireframe plan.

## MVP goal

The first version should help users:

1. View a job-search dashboard.
2. Save jobs they want to apply for.
3. Track application status.
4. Add job notes and links.
5. See progress toward getting hired.
